# Готовим вместе

Совместная готовка с нескольких телефонов. Один человек создаёт игру и выбирает рецепт, остальные сканируют QR-код. Дальше каждый видит на своём телефоне только свои шаги: кто освободился, сам выбирает, чем заняться дальше. Порядок рецепта соблюдается: шаг становится доступен только после тех, от которых он зависит.

**Играть:** https://romanglebov.github.io/gotovim-vmeste/

## Как играть

1. Откройте сайт на телефоне, выберите блюдо в «Книге рецептов», введите имя и нажмите «Создать игру».
2. Второй человек сканирует QR-код обычной камерой телефона (или вводит код из пяти букв через «Присоединиться по коду»).
3. Ведущий нажимает «Начать готовку». На экране «Вам понадобятся» все вместе отмечают инвентарь и продукты.
4. Готовьте: после «Готово» выбирайте следующее дело. Советуемый шаг выделен: после него откроется больше всего следующих.
5. В конце видна статистика: сколько занял каждый шаг. Её можно скопировать.

Экран не гаснет, пока идёт игра. Если телефон всё-таки закрыл страницу, откройте сайт снова: игра продолжится с того же места.

## Как это устроено

- **Только статические файлы.** Сайт лежит на GitHub Pages, сервер не нужен, всё бесплатно.
- **Связь между телефонами** идёт через бесплатный публичный MQTT-брокер (`broker.emqx.io`, при недоступности `broker.hivemq.com` или `test.mosquitto.org`). Телефон ведущего хранит состояние игры и рассылает его, остальные отправляют ему свои действия. Брокер хранит последнее состояние, поэтому телефон, который переподключился, сразу получает актуальную картину. Действия гостей повторяются, пока ведущий их не применит, так что ничего не теряется при плохой связи.
- **Готовить одному** можно и без связи: игра работает прямо на телефоне.
- Библиотеки mqtt.js и qrcode-generator (обе MIT) подключаются с jsDelivr.
- Код игры знают только участники, но брокер публичный: не пишите в имена ничего личного.

```
index.html          оболочка приложения
css/app.css         оформление
js/engine.js        правила игры: шаги, зависимости, инвентарь, таймеры (без интерфейса и сети)
js/net.js           связь между телефонами через MQTT
js/app.js           экраны телефона
recipes/            рецепты, по одному JSON-файлу на блюдо, и их картинки
docs/RECIPE_FORMAT.md   как писать рецепты
test/               автотесты
tools/dev-server.mjs    локальный сервер с собственным брокером
```

## Рецепты

Рецепты не зашиты в приложение. Каждый лежит отдельным файлом в `recipes/`, а список — в `recipes/index.json`. Чтобы добавить блюдо, положите файл в папку и допишите его имя в список. Формат описан в [docs/RECIPE_FORMAT.md](docs/RECIPE_FORMAT.md). Рецепт можно добавить и прямо на телефоне ведущего: «Книга рецептов» → «Добавить рецепт».

## Разработка

```bash
npm install
npm run dev        # http://localhost:8080/?broker=ws://localhost:8883 — откройте в двух окнах
npm test           # правила игры: каждый рецепт готовится до конца 1–3 поварами в разном порядке
npm run test:e2e   # два браузерных «телефона» готовят каждое блюдо через локальный брокер
```

Для `test:e2e` нужен Playwright: `npm i -D playwright && npx playwright install chromium`.
